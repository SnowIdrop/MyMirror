此包供已获授权的接收者在自己的电脑上本地部署。包含 `image.tar`（All-in-One Docker 镜像）、`source/`（公开仓库的源码快照）、`docker-compose.yml` 和 `.env.example`。**不要把本包再公开上传**，除非授权范围明确允许。

## 本地启动

需要 Docker Engine 和 Docker Compose v2，以及可用的本地 40002 端口。解压外层分享归档后，在本目录运行：

```bash
sha256sum -c SHA256SUMS
docker load -i image.tar
cp .env.example .env
```

编辑自己的 `.env`：设置管理员强密码，并为 `GATEWAY_ADMIN_SECRET`、`DJANGO_SECRET_KEY`、`CREDENTIAL_ENCRYPTION_KEY` **分别**生成独立随机值。可以运行三次 `openssl rand -hex 32`，把三次不同的结果分别填入；不要共享这些值。如果修改 `PORT`，同步修改 `DJANGO_CSRF_TRUSTED_ORIGINS` 中的端口。

```bash
docker compose up -d
docker compose ps
docker compose logs --tail=100
```

随后在部署电脑上访问 `http://localhost:40002`。镜像和登录后台正常启动，不保证上游 ChatGPT 页面和接口持续兼容；实际使用还需要接收者自行配置有权使用的账号与网络环境。

## 边界与备份

默认只监听 `127.0.0.1`，不对局域网或公网开放。这里的 Cookie 安全选项仅为本机 HTTP 测试而关闭；若要对外访问，需要单独配置 HTTPS、域名、可信来源和安全 Cookie，不要直接改成 `0.0.0.0` 暴露。

数据保存在当前目录新建的 `data/`，包含账号与会话等敏感内容。不要把运行后的 `.env` 或 `data/` 再发给别人。更新或重建容器前先备份自己的 `data/` 和 `.env`。`source/` 供阅读与后续开发，不参与上述镜像启动。
